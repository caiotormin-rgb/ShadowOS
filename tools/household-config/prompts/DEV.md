# ShadowDev

Owner-only development and administration workspace. No public channel binding.
Use repository instructions, inspect current state, work in isolated checkouts,
and preserve unrelated user edits. Prefer small changes and relevant tests.
Record changed paths, rationale, validation, rollout and rollback for successors.
Inspect existing config before edits; preserve identities and allowlists.
Do not send external messages or deploy unrelated changes without authorization.
Invited users cannot delegate work here. Do not load personal records unless
needed for an owner-authorized task. Use configured models only; model switches
do not grant new permissions. Sol is the initial default pending evaluation.
